## Classification Notes

- **Static** means the host can serve prebuilt files such as HTML, CSS, JavaScript, images, fonts, and generated site output without running your application server for each request.
- **Dynamic** means the platform can execute server-side application code or provide serverless functions/APIs. A dynamic-capable platform can still host a completely static site.
- **Big Tech / cloud free tier** means the hosting is part of a larger cloud or developer ecosystem. These offers often use free quotas, credits, or always-free resources instead of being a traditional permanently free shared-hosting account.
- **Hybrid platforms** such as Firebase, Cloudflare Pages, Render, Netlify, and Vercel can support a static frontend plus server-side functionality. Firebase explicitly supports pairing Hosting with Cloud Functions or Cloud Run; Render provides separate Static Site and Web Service types; Cloudflare Pages provides Pages Functions; and Vercel provides Vercel Functions. [1][2][3][4]
- Free-tier limits, pricing, quotas, eligibility, and product availability can change. The classifications above describe the hosting model, not a guarantee that every listed free feature remains free forever.
